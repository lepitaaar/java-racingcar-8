# java-racingcar-precourse

# 초간단 자동차 경주 게임
- [x] 횟수를 정한다.
- [x] 자동차를 입력한다.
  - [x] 자동차의 이름을 설정할 수 있다.
    - 5자 이하만 가능하다.
  - [x] 쉼표(,)로 구분한다.
- [x] 주어진 횟수(레이싱 횟수)동안 자동차가 이동한다.
  - 0~9의 무작위 값이 4이상일 경우 => 전진
  - 0~9의 무작위 값이 4미만일 경우 => 정지
- [x] 게임이 완료 후 누가 우승했는지 출력한다.
  - 우승자가 한 명 이상인경우 쉼표(,)를 이용해 구분한다.
- [x] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨다.

### 테스트 케이스
- [x] 자동차 이름이 5자 이하만 가능하다.
- [x] 자동차 이름은 특수문자를 포함하지않는다.
- [x] 자동차 이름 사이를 쉼표로만 구분해야한다.
- [x] 자동차 이름은 1자 이상이고 빈칸을 허용하지 않는다.
- [x] 레이싱 횟수는 1이상이어야 한다.

## 프로그램 구조
### 클래스 목록
    - Car
    - MoveStrategy
    - View
    - Game
#### Car
- 이름
- 전진하기
- 전진횟수

#### MoveStrategy
- isAvailableMove() 함수
  - 0~9 사이의 값이 4이상인지 판단해서 true/false 반환

#### View(Input & Output)
출력 관련 함수
- 이동 출력
- 우승자 결과 출력
- 자동차 입력
- 횟수 입력

#### Game
레이싱 게임 매니저
- 횟수 관리
- 자동차 목록
- Random을 사용하여 자동차 이동 관리
- 우승자
